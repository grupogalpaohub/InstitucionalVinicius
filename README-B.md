# Site Institucional Versão B - Vinícius Moraes | Emagrecimento Saudável

Versão moderna e dinâmica do site institucional para o nutricionista Vinícius Moraes, com design mais interativo e layout inovador.

## 🎨 Diferenças da Versão B

### Design e Layout
- **Navegação fixa** com efeito de transparência
- **Hero dinâmico** com formas flutuantes e estatísticas
- **Timeline vertical** para áreas de atuação
- **Carrossel interativo** para depoimentos
- **Layout magazine** para conteúdos
- **Animações suaves** e efeitos parallax

### Funcionalidades Avançadas
- **Carrossel automático** de depoimentos
- **Contador animado** para estatísticas
- **Efeito de digitação** no título principal
- **Lazy loading** para imagens
- **Navegação mobile** com hamburger menu
- **Efeitos de hover** mais elaborados

## ⚡ Performance

### Otimizações Implementadas
- **Lazy loading** para imagens
- **Intersection Observer** para animações
- **CSS Grid** e **Flexbox** para layouts
- **Transições GPU** aceleradas
- **Debounce** em eventos de scroll

### Métricas Esperadas
- **First Contentful Paint**: < 1.5s
- **Largest Contentful Paint**: < 2.5s
- **Cumulative Layout Shift**: < 0.1
- **First Input Delay**: < 100ms
