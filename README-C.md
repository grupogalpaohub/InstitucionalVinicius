# Site Institucional Versão C - Vinícius Moraes | Emagrecimento Saudável

Versão focada em conteúdo educativo e audiovisual, com destaque para vídeos, lives e interatividade, mantendo a mesma paleta de cores mas com um layout mais dinâmico e educativo.

## 🎥 Diferenças da Versão C

### Foco em Conteúdo Educativo
- **Seção de vídeos e lives** dedicada
- **Cards de vídeo** com thumbnails e controles
- **Badge de vídeo** no hero
- **Layout magazine** para conteúdos
- **Schema JSON-LD** para SEO avançado

### Design e Layout
- **Navegação com logo** e CTA destacado
- **Hero com storytelling** e estatísticas
- **Cards interativos** com features
- **Carrossel avançado** de depoimentos
- **Seção de vídeos** com controles de reprodução

## ⚡ Performance

### Otimizações Implementadas
- **Lazy loading** para imagens
- **Intersection Observer** para animações
- **CSS Grid** e **Flexbox** para layouts
- **Transições GPU** aceleradas
- **Debounce** em eventos de scroll

### Métricas Esperadas
- **First Contentful Paint**: < 1.5s
- **Largest Contentful Paint**: < 2.5s
- **Cumulative Layout Shift**: < 0.1
- **First Input Delay**: < 100ms
