# Site Institucional - Vinícius Moraes | Emagrecimento Saudável

Site institucional responsivo para o nutricionista Vinícius Moraes, focado em emagrecimento saudável e nutrição sem complicação.

## 🎨 Design e Cores

### Paleta de Cores
- **Verde Sálvia**: `#6BAA75` (cor principal, equilíbrio e saúde)
- **Verde Escuro**: `#264E36` (títulos e chamadas)
- **Bege Claro**: `#F6F1EB` (fundos leves)
- **Cinza Grafite**: `#3A3A3A` (textos corridos)
- **Amarelo Suave**: `#F2C94C` (CTAs e destaques)

### Tipografia
- **Títulos**: Poppins Bold
- **Subtítulos/Destaques**: Nunito SemiBold
- **Texto corrido**: Open Sans Regular

## 📱 Responsividade

O site é totalmente responsivo e otimizado para:
- **Desktop**: Layout em grid com duas colunas
- **Tablet**: Adaptação para telas médias
- **Mobile**: Layout em coluna única com otimizações touch

## 🚀 Como Usar

1. **Abra o arquivo `index.html`** em qualquer navegador moderno
2. **Personalize as imagens** substituindo os placeholders:
   - `hero_vini.jpg` - Foto principal do Vinícius
   - `sobre_vini.jpg` - Foto profissional
   - `Depoimento1.png`, `Depoimento2.png`, `Depoimento3.png` - Depoimentos
   - `og_vinicius.jpg` - Imagem para redes sociais

3. **Configure os links** nos botões de CTA:
   - Links para e-book gratuito
   - Sistema de agendamento
   - Redes sociais
   - Blog/conteúdos

## 🎨 Personalização

Para personalizar o site:

1. **Cores**: Edite as variáveis CSS em `:root` no arquivo `styles.css`
2. **Conteúdo**: Modifique os textos diretamente no `index.html`
3. **Imagens**: Substitua os placeholders pelas imagens reais
4. **Links**: Atualize os hrefs dos botões e navegação
