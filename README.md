# Site Institucional - Vinícius Moraes | Emagrecimento Saudável

Site institucional responsivo para o nutricionista Vinícius Moraes, especialista em emagrecimento saudável.

## 🚀 Características

- **Design Responsivo**: Adaptável a desktop, tablet e mobile
- **Header e Footer Reutilizáveis**: Objetos JavaScript para consistência
- **SEO Otimizado**: Meta tags, Open Graph e estrutura semântica
- **Acessibilidade**: Foco em navegação por teclado e leitores de tela
- **Performance**: CSS otimizado e carregamento eficiente

## 📁 Estrutura do Projeto

```
/
├── index.html               # Página inicial (raiz do site)
├── produtos.html            # Página de produtos/serviços
├── contato.html             # Página de contato com formulário
├── blog.html                # Página do blog
├── termos-de-uso.html       # Termos de uso
├── politica-privacidade.html # Política de privacidade
├── styles.css               # CSS comum para todas as páginas
├── header.js                # Objeto JavaScript do header
├── footer.js                # Objeto JavaScript do footer
└── README.md                # Documentação do projeto
```

## 🎨 Design System

### Cores
- **Verde Salgia**: #6BAA75 (cor principal)
- **Verde Escuro**: #264E36 (títulos e textos importantes)
- **Bege Claro**: #F6F1EB (backgrounds suaves)
- **Cinza Grafite**: #3A3A3A (textos)
- **Amarelo Suave**: #F2C94C (destaques)

### Tipografia
- **Títulos**: Poppins (700, 600, 400)
- **Subtítulos**: Nunito (700, 600, 400)
- **Textos**: Open Sans (600, 400, 300)

### Componentes
- **Botões**: Gradientes com hover effects
- **Cards**: Sombras suaves e bordas arredondadas
- **Formulários**: Validação visual e acessibilidade
- **Navegação**: Menu responsivo com scroll effect

## 🔧 Funcionalidades

### Header Comum
- Logo com ícone e texto
- Menu de navegação responsivo
- Botão CTA "Consulta Grátuita"
- Efeito de scroll (muda aparência ao rolar)
- Menu mobile com toggle

### Footer Comum
- Informações de contato
- Links para todas as páginas
- Links para produtos
- Redes sociais
- Links legais (Termos e Privacidade)

### Páginas Específicas

#### Início
- Hero section com CTA

#### Produtos

#### Blog

- Conteúdo estruturado e acessível

## 📱 Responsividade

- **Desktop**: Layout em grid com sidebar
- **Tablet**: Adaptação de colunas e espaçamentos
- **Mobile**: Layout em coluna única, menu hambúrguer

## ♿ Acessibilidade

- Navegação por teclado
- Estados de foco visíveis
- Alt text para imagens
- Estrutura semântica HTML5
- Contraste adequado
- Suporte a leitores de tela

## 🚀 Como Usar

1. **Abrir qualquer página HTML** no navegador
2. **O header e footer são aplicados automaticamente** via JavaScript
3. **Navegação funciona** entre todas as páginas
4. **Formulários têm validação** básica implementada
